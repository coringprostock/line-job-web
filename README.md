# ระบบงานช่าง — หน้าเว็บ (LIFF)

หน้าเว็บที่เปิดใน LINE สำหรับดูและอัปเดตงานซ่อม: บอร์ดงาน · หน้างาน (แถบสถานะ + ไทม์ไลน์ + รูป) · คิวตรวจข้อเสนอของ AI

- ไฟล์ทั้งหมดเป็น public (GitHub Pages) **ห้ามใส่ความลับ**
- ข้อมูลทั้งหมดมาจาก Apps Script (`config.js` → `API_URL`) ซึ่งตรวจ ID token ของ LINE และชื่อในชีต Staff ทุกคำขอ
- โค้ดฝั่งเซิร์ฟเวอร์อยู่ที่โปรเจกต์ `line-job-tracking` (`src/webapi.gs`)
